# AGENTS.md — lucila-safdie (Shopify Dawn + Tailwind Theme)

## What this repo is

A **Shopify 2.0 theme** based on Dawn v15.2.0 with Tailwind CSS integration. Built by Trellis Commerce.
**Not a Node.js app** — no tests, no bundler, no framework. It's a Shopify theme.

## Quick start

```bash
node -v  # must be v18 (per .nvmrc)
npm install  # installs husky, lint-staged, prettier, tailwindcss
shopify theme dev  # local dev server (requires Shopify CLI)
```

## Directory ownership

| Directory | What it is |
|-----------|-----------|
| `layout/*.liquid` | Theme layouts (theme.liquid, password.liquid) — the HTML shell |
| `sections/*.liquid` | 50+ draggable section templates (Liquid) |
| `sections/*.json` | Section group definitions (header-group, footer-group) — **edited by Shopify admin, auto-generated** |
| `snippets/*.liquid` | 70+ reusable partial components |
| `templates/*.json` | Page/product/collection template configs (Shopify 2.0 style — **no .liquid template files**) |
| `templates/*.liquid` | Only `gift_card.liquid` — the sole Liquid template file |
| `assets/*.css` | Compiled CSS (Dawn base.css + Tailwind-generated app.css) |
| `assets/app-tailwind.css` | Tailwind source: `@tailwind base/components/utilities` only |
| `locales/*.json` | 30 locale files (translations) |
| `config/*.json` | Theme settings schema and data |
| `.shopify/metafields.json` | Product/page metafield definitions (clothing/apparel focus) |

## Tailwind CSS — critical quirks

- **Prefix**: `twcss-` (all custom Tailwind classes must use this prefix)
- **Important**: `important: true` — Tailwind classes use `!important` to override Dawn base styles
- **Source**: `assets/app-tailwind.css` → **Compiled**: `assets/app.css`
- **Generate**: `npx tailwindcss -i ./assets/app-tailwind.css -o ./assets/app.css`
- **CI**: On push, `ZoeyVid/tailwindcss-update` action auto-generates `app.css` and commits it
- **Post-checkout hook**: `git update-index --skip-worktree assets/app.css` — app.css is marked skipped after checkout so local changes don't conflict. **Do not edit app.css directly** — edit app-tailwind.css and regenerate.
- **Liquid + Tailwind gotcha**: A Tailwind class immediately followed by a Liquid tag causes compile issues. Put a space between: `twcss-px-4 {% endif %}` works; `twcss-px-4{% endif %}` breaks.
- **CSS load order** in theme.liquid: `app.css` loads before `base.css` so Tailwind takes precedence. Swapping the order reverts to Dawn styles.

## Pre-commit hooks

- **Pre-commit**: `npx lint-staged` → formats `*.{js,css}` with Prettier
- **Post-checkout**: marks `assets/app.css` as `skip-worktree`
- **Prettier config**: `.prettierrc.json` — single quotes for JS/CSS, **double quotes for Liquid**

## Theme Check (Shopify linting)

- Runs in CI via `shopify/theme-check-action`
- Runs locally via VSCode extension (`themeCheck.checkOnSave: true`)
- **Disabled rules**: `MatchingTranslations`, `TemplateLength` (per `.theme-check.yml`)
- Recommended VSCode extensions: `shopify.theme-check-vscode`, `esbenp.prettier-vscode`

## Templates — Shopify 2.0 style

Templates are defined via `.json` files, **not** `.liquid` files. Each `templates/X.json` declares which sections render that template. The actual Liquid rendering logic lives in `sections/`.

- **Context variants**: `*.context.gb.json` and `*.context.international.json` files exist for regional template overrides (e.g., GB vs international shipping/taxes)
- **Custom page templates**: `page.fw26-lookbook.json`, `page.newsletter.json`, etc. — custom page templates with specific section layouts
- **`page.noindexnofollow.json`**: Adds `noindex, nofollow` meta robots tag

## Section groups

- `header-group.json` / `footer-group.json` — section group definitions (auto-generated by Shopify admin)
- Context variants: `header-group.context.gb.json`, `footer-group.context.international.json`, etc.

## Localization

- 30 target languages configured in `translation.yml`
- Two component types: `buyer` (locales/{{language}}.json) and `merchant` (locales/{{language}}.schema.json)
- `MatchingTranslations` rule is disabled — translations may not be complete across all locales

## External integrations

- **Klaviyo**: Account `RxJGVR` — back-in-stock notifications injected in theme.liquid
- **Shopify Metafields**: Defined in `.shopify/metafields.json` — clothing-specific (size, fabric, fit, etc.) for products; care instructions for pages

## CI workflow (`.github/workflows/ci.yml`)

Three jobs run on push:
1. **tailwindcss-update** — generates `assets/app.css` from `app-tailwind.css` and commits
2. **lhci** — Lighthouse CI (requires GitHub secrets: `SHOP_ACCESS_TOKEN`, `SHOP_STORE`, etc.)
3. **theme-check** — Shopify Theme Check linting

## Shopify CLI commands
